# Phase 9 labeled demo script

The demo uses only the accepted local AAOS runtime and sanitized synthetic
fixtures. Real local behavior is labelled separately from deterministic fake
adapter behavior and synthetic data. No step performs an external write.

1. Open the local dashboard and show the same-origin academic surfaces.
2. Run a grounded local RAG question; show a trusted citation or the honest
   `INSUFFICIENT_EVIDENCE` result.
3. Show a multimodal derived-evidence citation without presenting it as exact
   embedded PDF text.
4. Run the restricted computation fixture; label the sandbox adapter as fake.
5. Review the fake approval lifecycle, including the distinct
   `UNKNOWN_OUTCOME` reconciliation state.
6. Open Activity and passive System Health.
7. Use only sanitized synthetic fixtures; do not display private university
   data, credentials, cookies, OAuth state, or provider payloads.

The historical Phase 6B Google Calendar CREATE is documented as one accepted
historical external write. It is not repeated by this demo and does not imply
ongoing provider availability.
