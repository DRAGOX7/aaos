# Phase 7 — Approved Dashboard Visual Reference

`aaos-dashboard-approved-reference.png` is the approved visual reference for
the Phase 7 AAOS dashboard.

It governs visual direction only, including:

- layout and information hierarchy;
- light academic SaaS appearance;
- sidebar/navigation treatment;
- spacing and density;
- typography hierarchy;
- rounded surfaces;
- borders and subtle elevation;
- restrained blue, teal, and pastel accents;
- icon treatment;
- responsive visual behavior.

Product scope and feature authority remain defined by:

`docs/superpowers/specs/2026-09-16-phase-7-dashboard-operational-visibility-design.md`

Illustrative content in the mockup is not automatically a product requirement.
Fake counts, sample schedules, analytics, notifications, course records, tasks,
approvals, health metrics, and other demonstration data must not be implemented
unless backed by approved AAOS functionality and authoritative backend
contracts.

The visual reference may shape presentation. It must never expand product
scope.
