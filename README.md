# AAOS

AAOS (Autonomous Academic Operating System) is a local-first system intended to help users observe, reason about, and act within academic environments through a controlled orchestration layer and trusted tools.

## Development status

Current implementation: Phase 0B — Python environment/tooling implemented, Phase 0 still in progress.

Development is governed by the phase gates in [`docs/PHASES.md`](docs/PHASES.md). No application implementation has begun.
