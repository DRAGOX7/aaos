# AAOS

AAOS (Autonomous Academic Operating System) is a local-first system intended to help users observe, reason about, and act within academic environments through a controlled orchestration layer and trusted tools.

## Development status

Current implementation: Phase 0C — minimal FastAPI foundation implemented; Phase 0 remains in progress.

Development remains governed by the phase gates in [`docs/PHASES.md`](docs/PHASES.md). Phase 0 is not complete.
